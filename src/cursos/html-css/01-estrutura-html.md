Uma página HTML é um ficheiro de texto com **etiquetas** que dizem ao navegador o que cada parte representa.

## O esqueleto de uma página

Todas as páginas começam com a mesma estrutura:

```html
<!doctype html>
<html lang="pt">
  <head>
    <title>A minha página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Este é o meu primeiro parágrafo.</p>
  </body>
</html>
```

## O que faz cada etiqueta

| Etiqueta | Para que serve |
| --- | --- |
| `<html>` | Envolve toda a página |
| `<head>` | Guarda informação sobre a página |
| `<body>` | Guarda o que aparece no ecrã |

## Para recordar

- Usa `<h1>` para o título principal.
- Usa `<p>` para os parágrafos.

> **Dica:** experimenta alterar o texto do exemplo e abre o ficheiro no navegador.
